Financial: billing review for finance staff

Who you are + scope

You review and settle what CLOACK bills. You are a member of the Financial group: you see the Billing Report, the Billing Report by PI and IO Numbers, but only for the affiliations a superuser granted you. You are not portal staff: no other staff page opens for you, and you have no cluster account unless you also run jobs.

What decides "your" rows is the project's affiliation, not the PI's. A PI may own projects under two affiliations; each project's charges belong to the affiliation the project was created under.

Quick start

1. Get access

  1. Sign in to the portal once, so your account exists.
  2. Ask a superuser to add you to the Financial group and to grant the affiliation(s) you cover (see superuser.md, "Grant the Financial role").
  3. Reload: a Billing entry appears in the sidebar (or in the top bar, depending on the portal theme), with the three pages. Each page shows a blue note naming the affiliations you are looking at.

2. Close a month

  1. Staff run Compute Billing for the month. Until they do, the month has no periods and the CSVs do not exist.
  2. Open Billing Report, pick the month, keep Billable only on, and review the rows (one per allocation).
  3. Download the files you send on: Billing File (PI / IO / Total), IO (totals per IO), Detail (per allocation), Chargebacks (credits and debits) and PDF. Per-period invoices are the PDF / TXT / Detail buttons on each row.
  4. Record what happened: set each period's Payment Status, and use Credit for a refund or correction (the reason is kept for the audit trail).

3. Look after IO Numbers

IO Numbers lists every IO in your scope with the projects and allocations it funds and whether it is paused. Edit changes the label, type, direction and availability; the pause button stops billing on that IO.

Reference matrices

Payment status

Status Meaning Side effect
Pending Invoiced, not yet paid None
Paid Settled Lifts an automatic pause once no other Overdue period remains on that IO
Overdue Unpaid past due After the grace window set in Billing settings, every IO paying that allocation is paused: billing stops, job submission is held, a helpdesk ticket opens
No Charge Not billed No charge for that period; lifts an automatic pause like Paid

Marking a period Overdue can stop a lab's jobs once the grace window passes, so set it on purpose.

Pausing an IO

Effect
Pause The IO is not charged, cannot fund new work, and job submission is held on every paid allocation it alone funds. A helpdesk ticket opens with the PI as requester.
Resume Billing and job submission come back on the next sync; the ticket is resolved.
Refused No-charge IOs, IOs funding a hardware-credit (condo) allocation, and IOs sharing an allocation with another live IO cannot be paused. The page says why.

Which file you get

Your scope Billing File / IO / Detail / Chargebacks / PDF
One affiliation That affiliation's version, written in the same Compute Billing run with the same numbers
Every affiliation The full file
Several, but not all Refused (no single file matches); ask a superuser

Troubleshooting

What you see Cause What to do
"No affiliation is assigned to your Financial role" You are in the group but no affiliation was granted Ask a superuser to grant one
No Billing entry in the menu You are not in the Financial group, or the page was open before the change Reload; otherwise ask a superuser
"Report file not found" Compute Billing has not run for that month, or ran before per-affiliation files existed Ask staff to run Compute Billing for that month again
"Outside your affiliation scope" on a status change or credit The project belongs to an affiliation you were not granted Ask a colleague who covers it, or a superuser
IO Edit returns "not found" That IO funds no project in your scope Same as above
The portal shows a maintenance page During a maintenance lockout only staff can sign in Wait for the window to end
